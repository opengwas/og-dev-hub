Pipeline

The path data takes through the system, from a source file to a query: the stages, the components that do each one in every repository with a model, and the architecture decisions (ADRs) that govern them.

See also Structure and health.

Written by hand: the stages and their order, which stages each component serves, each component’s name, summary and the code paths it claims. Each is in a repository’s docs/architecture/components.yaml.

Measured: each component’s code size, the ADRs placed on it (by the code an ADR cites and by component names in its title), and the commit read in each repository. Nothing measured is written by hand, so it cannot drift from the code.

6 repositories have no architecture model yet: opengwas-gateway, opengwasdb-website, og-dev-hub, agent-skills, opengwaspy, opengwasr. Their components, layers and imports are unknown, not none, and each is drawn as its containers only.

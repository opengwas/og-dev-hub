Epic: Cut Store Release Build, validation and Reference Completion wall time by removing repeated and single-process work

Purpose

A full Store Release takes about a day of wall time, even outside the nightly backup window. OGS-00009 (2,514 Analyses × 9.85M variants), together with its Reference Completion, needs about **27 hours**. Most of that time goes to work that is either:

Epic #307 removed repeated full-plane work, parallelised validation, encoding, Top-Hit scanning and completion writes, and replaced row-wise Pass 2 bottlenecks with exact columnar paths while retaining the Python reference implementations. The final OGS-00009 scratch release completed in 7h50m34.998s, 23.228% faster than the prior run and 1h09m25.002s inside the nine-hour gate, with clean validation and zero observed-view mismatches across 2.681 billion cells. Engine v0.10.0 and the matching stores contracts are released; value-changing completion work remains separately specified in #423, and no production reference regeneration was part of this epic.

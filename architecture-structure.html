Structure and health

How the system fits together at three levels (C4): who and what it talks to, its containers, and the components inside each repository with a model, with the imports within and between them.

See also the Pipeline.

Written by hand: the system context, the containers and how they relate, the layers a model declares (the intended layering, a decision rather than a measurement) and the code each component claims. The system context, the containers and the list of repositories are og-dev-hub’s system.yaml; the layers and claims are in each repository’s docs/architecture/components.yaml.

Measured: the imports between components (counts, read from the code of every repository with a model), which of them go against the layering, the imports across repositories, and the gaps in the claims. Nothing measured is written by hand, so it cannot drift from the code.
